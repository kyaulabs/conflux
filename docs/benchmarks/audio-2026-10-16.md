# M0 laptop audio and rendering measurements

Measured on 16 October 2026 on aura, the primary ThinkPad X1 Carbon Gen 9:
i7-1185G7, Intel Iris Xe TGL GT2, Arch Linux kernel
`7.2.10-hardened1-1-hardened`, Qt 6.12.0, PipeWire 1.6.9, GCC 16.2.1,
CMake 4.4.4 and Ninja 1.13.2. The desktop remained running. These short probes
do not establish thermal stability, musical quality or the first usable release
configuration.

The PipeWire daemon reported a default 48 kHz / 1024-frame graph before testing.
Each stream requested its own quantum with `node.latency`. No global settings
were changed. Runs were sequential, with separator inference stopped. The
256-frame run overlapped the small Qt smoke test and application build; this
was not an isolated CPU benchmark. Raw reports are in
[data/audio-256.json](data/audio-256.json) and
[data/audio-512.json](data/audio-512.json).

Callback durations include buffer dequeue, generation, queue and instrumentation.
The default signal was silence. Percentiles use 1 µs histogram buckets and are
reported as upper bounds. The graph snapshots are PipeWire-reported delay,
not measured speaker or headphone latency. The recovery flag comes from
`SPA_IO_Position::clock`, the graph driver's position clock. Per-stream xrun
recovery and a complete graph-wide xrun count are unmeasured. A physical loopback
and listening check remain outstanding. The raw reports' field was corrected
from `observed_node_xrun_recovery_flags` to
`observed_position_clock_xrun_recovery_flags`; all measured numerical values are
unchanged. These baseline reports preceded the optional telemetry guards for
older PipeWire headers; the local 1.6.9 measurement path is unchanged.

The native Wayland smoke test exposed a 640 × 400 logical window at device pixel
ratio 2 and swapped 104 frames in approximately two seconds using OpenGL
(`QSGRendererInterface::OpenGL`, enum 3). A software/offscreen smoke test also
rendered successfully, using enum 1. The tests loaded the approved SVG logo,
fonts and theme singleton. The brand pack's supplied checksum manifest passed
without modifications. The AGPLv3 LICENSE hash remains
`8486a10c4393cee1c25392769ddd3b2d6c242d6ec7928e1414efff7dfb2f07ef`.

The CMake build and both CTest cases passed. The core test compares exact samples
from one offline render with varying live callback sizes across table wraps,
and checks silence, stereo equality, finite values, gain limits and incomplete
frame rejection. No audio device is required for these tests. CI additionally
checks QML with offscreen software rendering; real Wayland and device behavior
remain development-machine checks.

Further runs used AC power with the CPU governor reporting `powersave`.
The default OpenGL window and silent 256-frame output ran together for 60 seconds
without inference: 3,584 window frames, 11,245 audio callbacks, p99.9 at most
40 µs and maximum 53.102 µs. No buffer faults, execution deadline misses or
position discontinuities were observed. Reports are
[UI](data/ui-opengl-baseline.json) and
[audio](data/audio-256-ui-baseline.json).

The Vulkan window and silent output then ran for 45 seconds, containing the
entire 23.4-second HTDemucs Vulkan request. The UI report file opened at
`07:30:29.439 UTC` and completed at `07:31:14.974 UTC`; audio ran from
`07:30:30.623` to `07:31:15.735 UTC`. Inference occupied
`07:30:37.476` to `07:30:45.441 UTC`. This run swapped 2,720 window frames with
Vulkan (enum 5), processed 8,454 audio callbacks, and recorded p99.9 at most
22 µs and maximum 31.555 µs. The fault counters remained zero. These are
whole-interval aggregate percentiles; inference occupied only about eight
seconds. The opening portion also overlapped the quiet-tone capture below.
Reports are [UI](data/ui-vulkan-contention.json) and
[audio](data/audio-vulkan-contention.json). Separator timings and their limits
are in [the stem report](stems-2026-10-16.md).

The same separation request also ran under the default OpenGL window. UI ran
from `07:31:41.232` to `07:32:11.955 UTC`, audio from `07:31:38.777` to
`07:32:08.896 UTC`, and inference from `07:31:49.733` to approximately
`07:31:59.467 UTC`. The UI swapped 1,813 frames. Audio processed 5,621 callbacks
with p99.9 at most 40 µs, maximum 82.545 µs and zero observed fault counters.
Reports are [UI](data/ui-opengl-contention.json) and
[audio](data/audio-opengl-contention.json). One run per renderer cannot rank
renderer performance reliably; both short workloads completed successfully.

A ten-second quiet-tone run produced no observed callback/buffer faults.
A direct monitor of `conflux-audio-probe` captured 240,000 stereo frames at
48 kHz, with a 440 Hz spectral peak, peak amplitude 0.0099999998, RMS 0.00706726
and identical channels. This verifies digital signal delivery, not speakers,
headphones, acoustic latency or listening quality. No microphone was captured.
Reports are [probe](data/audio-tone.json) and
[monitor](data/tone-monitor.json). Start the probe with `--tone`, then use:

```sh
pw-record --target conflux-audio-probe --container wav --format f32 \
  --rate 48000 --channels 2 --sample-count 240000 /tmp/conflux-tone.wav
```

The installed `pw-record` returned 1 after reaching the sample limit. Its
[1.6.9 source](https://github.com/PipeWire/pipewire/blob/1.6.9/src/tools/pw-cat.c)
quits at the limit but sets a success exit code only on its drained path. The
file was independently decoded with FFmpeg and checked for the full frame count,
format and expected signal; the exit code alone was not treated as success.

Reproduce the harness with [M0.md](../M0.md). Staged installation and desktop-entry
validation also passed. The full 60-minute two-deck/cue/recording/effects/stem
soak belongs to a later working processing graph and has not been run.
