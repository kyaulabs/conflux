# M0 controlled repaint cadence soak

Reducing repaint cadence did not meet the M0 delivery target. The laptop
completed a 60-minute worker/audio/UI run at approximately 31.25 frame
notifications per second: continuous-hop p99 was **5.087 seconds** against
**4.095 seconds**, with **178/1,416 misses** and a **7.475-second maximum**.
All eleven cancellation/seek controls passed, all six audio fault counters
were zero, and no sustained high heat was observed in the sampled sensors.
Benchmarking is stopped; M1 has not started.

Frame rates are complete-minute GUI observations. Percentiles use nearest
rank; serial windows are not independent tail samples. The hour lasted
3,600.000290 seconds. Including eleven seek replacements gives 1,427 hops
with the same p99, maximum and miss count. Its first five-minute all-hop bin
had p99 2.410 seconds and zero misses. All eleven later complete bins exceeded
the target, with p99 4.455–6.568 seconds. No startup interval was removed;
the empty final partial bin remains in the evidence.

Commit `d00692f` adds the benchmark-only `CONFLUX_M0_REPAINT_MS` control.
It accepts exactly `16` or `33` with `--smoke-test`, using an independent
[QTimeLine update interval](https://doc.qt.io/qt-6/qtimeline.html#updateInterval-prop)
for the existing 3.2-second eased motion. Reduce motion pauses and resumes
the same phase. Unset behavior keeps the original animation. This controls
animation updates, not a global frame-rate limit.

Both short trials used the same new UI binary and protocol; only the
configured interval differed. The build and all three existing CTests passed.
Strict argument checks passed, and ten behavior assertions at each interval
verified motion, bounds and Reduce motion pause/resume through actual QML
controls. Native short trials confirmed motion and cadence; each also passed
one cancellation/seek check with zero audio faults.

The full hour kept Vulkan, four inference threads, blocking fence waits,
passive child-only OpenMP settings, request timeout and sampler unchanged.
Seven producer/runtime/model/audio hashes, the fixture hash and all nine
reference-window hashes match the
[previous Vulkan hour](ui-profile-2026-10-17.md). The UI binary intentionally
changed. The previous hour measured 5.570 seconds p99 and a 6.296-second
maximum with the original NumberAnimation. Fixed order, different background
load, cache/power history and the changed animation driver prevent attributing
the difference to cadence. Neither hour meets the target.

Native graph p99 was 4.935 seconds; queue-delay p99 was 0.677 ms.
Hop time minus graph time had p99 180.711 ms; this interval difference is not
an isolated CPU/transport measurement. All 1,416 continuous hops were sampled
in balanced mode with `balance_performance` EPP. The 178 misses had mean
interior GPU-frequency samples of 385.7–643.8 MHz, median 566.7 MHz; non-miss
hops had median 1,137.5 MHz. These are unweighted means of discrete snapshots,
not effective frequency or proof of a cause. Multi-second delays remain
primarily in native execution/wait. The earlier 10.813-second stall did not
recur. The bounded kernel query found no matching graphics/fence/reset records
and returned no query or parse errors.

All eleven controls rejected invalidated held chunks and matched discarded
results to their superseded generation/request. No stale or post-cancel chunk
reached the consumer. Recorded exact/numerical seek parity had zero maximum
absolute difference; successful PCM arrays were not retained for recomputation.
Cancellation acknowledgement took 0.021–0.251 ms, active native drain
1.927–2.054 seconds and replacement delivery after cancellation
6.212–6.570 seconds. Cancellation remains logical; hardware submission and
GPU preemption were not observed. One backend stayed resident, queue high
water was one against a two-hop bound, no telemetry was dropped, and the
worker closed cleanly.

The independent silent audio probe covered the full workload with 675,297
callbacks and 172,876,032 frames at 48 kHz stereo with 256-frame stream/graph
quanta. Deadline misses, missing/invalid buffers, truncation, observed
graph-position discontinuities and clock recovery flags were all zero.
Callback p99.9 had a 20-microsecond histogram upper bound; maximum execution
was 235.783 microseconds. This assesses the available laptop callback/transport
path without requiring an external interface or perfect device timing.
Actual stem playback, physical latency and complete graph xrun accounting
remain unmeasured.

The UI produced 112,549 frame notifications across sixty complete minute bins,
with a 73.541 ms maximum notification gap and zero sampled exposure loss.
Eighty saved workload position samples spanned the full 0–300 range with
Reduce motion disabled. Native Wayland and Vulkan graphics API 5 were confirmed.
These GUI observations do not measure physical presentation or interaction
latency.

The 7,067 workload thermal snapshots peaked at 80°C for the package and
73.05°C for TCPU; none reached 85°C or 95°C. Maximum adjacent sample gap was
0.684 seconds. Six other mapped sensors were not sampled. Brief ultrabook
spikes remain acceptable; peak alone is not a failure, and no sustained-duration
threshold was invented. Readiness records retain thermal-guard warnings before
admission. The unchanged guard recovered naturally; the runner never set or
restored a profile. The hour received the existing ten-minute minimum cooldown
and consecutive sixty-second balanced/no-hold/recovery gate.

All 79 workload AC/lid snapshots showed AC online and lid open, with no
observation errors. Maximum adjacent gap was 46.649 seconds; the first was
25.135 seconds after workload start and the last 14.075 seconds before stop.
Conditions between snapshots remain unobserved.

The [evidence manifest](data/cadence-2026-10-17/manifest.json) covers compressed
raw events/traces, exact producer and verification sources, independent audits,
analysis, corrected verification attempts and cleanup records. Packaged replay
checks reproduce the seven cadence/event/thermal audits and the completed-hour
summary from saved bytes. Model weights, binaries and generated WAV/F32 audio
are excluded. All fixtures were removed, workers/probes exited, owned window
and sleep/idle guards were released, and the finite sequence/monitors exited.
No further benchmark is running or scheduled.
