[Coverage job 123911098830](https://github.com/kyaulabs/conflux/actions/runs/41009231581/job/123911098830) failed the generated prefader-EQ cue assertion after a routing rebuild. Its first cue check had zero errors; the second recorded **110 wrong samples, all zero**, across 1,024 checked frames per channel. The rebuilt output clock advanced from 1,024 to 5,120 before validation. The earlier fresh-output settling condition was satisfied. The original failure remains unexplained and retained.

The job captured 89.21% C++ and 87.08% Python line coverage, but execution failed. Those are incomplete measurements. Normal Linux tests and the source-push coverage job on the same head passed; their successes do not explain the failed sample interval.

The fixture now records wrong/zero counts before each cue check, valid-buffer frame counts while validation is armed or disarmed, and the first mismatch's graph position/time, channel, frame, callback size and first/last values. A release/acquire latch publishes the fixed first-error record once; the audio callback performs no allocation or logging. Failure output also retains source cursors, starvation, buffering, read errors and queue/buffer health before shutdown. This distinguishes an error already accumulated before validation from a new error in the asserted interval. Existing readiness, settling duration, sample tolerance and zero-error assertions are unchanged.

Two local complete preparation suites passed all **160 checks**. A separate bounded EQ-only probe passed **20 rounds** of the existing controller/routing/recording sequence. That helper used an unoptimized test translation unit with the cached Release audio/UI libraries; it does not reproduce CI's fully instrumented build or explain its failure.

A private fault-injection copy set cue gain to zero before the first check. The original assertion correctly rejected **2,048 wrong/zero samples**, with zero preexisting errors. The new first-error record identified a zero sample, and the failure-time audio state retained healthy sources with no starvation. This verifies that bad cue PCM still fails and that the added diagnostics work. The injected control exists only in the private probe, outside the repository fixture and product.

Every local private graph and daemon was cleaned up, with no nodes or links left beyond the expected dummy driver before teardown. No model, GPU or physical audio was used. The accepted CONFLUX client binary stayed byte-identical. The [manifest](data/cue-mismatch-trace-2026-10-29/manifest.json) binds the failed CI artifact, original/current source snapshots, build commands, full positive captures, all EQ rounds and the deliberate-silence rejection.
