# M0 build and audio harness

This slice establishes a C++20 build, a small Qt Quick rendering window and a
headless PipeWire output probe. It does not implement DJ decks or separation in
the application. The accepted product requirements remain in
[the development handoff](handoff/PLAN.md).

Before committing, run `pnpm install --frozen-lockfile` and
`git config core.hooksPath .github/hooks`. The supplied hooks run Gitleaks and
the pinned local commitlint packages. The original global commitlint install
could not resolve its configuration from this checkout, so the development
manifest records that existing hook requirement. Node and pnpm are development
tools and are not application runtime dependencies.

On Arch, the installed build dependencies are `base-devel`, `cmake`, `ninja`,
`pkgconf`, `qt6-base`, `qt6-declarative`, `qt6-svg` and `pipewire`. The worker
tests also require Python 3.11 or newer and NumPy. The installed
Qt 6.12 package includes the Wayland client plugin. Confirm the plugin in the
target distribution rather than assuming every release has the same package
split. Models and experiment builds are separate from the application build.

```sh
cmake -S . -B build/dev -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build/dev --parallel 2
ctest --test-dir build/dev --output-on-failure
QT_QPA_PLATFORM=wayland build/dev/conflux
```

The window uses the unmodified version 1.1 brand palette, outlined SVG lockups
and bundled fonts. Use `--light` to start light. F6 switches the theme; Ctrl+Q
closes it. The moving indicator
provides a small rendering workload for contention experiments. It is not the
performance interface. `com.kyaulabs.conflux` identifies both the desktop entry
and the Wayland window. Installation also includes the font notices and AGPLv3
license. Stage an installation without changing the running desktop:

```sh
DESTDIR="$PWD/build/stage" cmake --install build/dev --prefix /usr
QT_QPA_PLATFORM=wayland build/dev/conflux --smoke-test --screenshot /tmp/conflux-m0.png
QSG_RHI_BACKEND=vulkan QT_QPA_PLATFORM=wayland build/dev/conflux --smoke-test
```

The smoke test requires an exposed window and completed frames. Its JSON records
the platform, Qt version, actual graphics API enum, frame count and window size.
The usual Qt Quick renderer and stem inference backend are independent choices.
An offscreen software smoke test in CI only checks QML loading/rendering.

```sh
build/dev/conflux-audio-probe --seconds 30 --quantum 256
build/dev/conflux-audio-probe --seconds 30 --quantum 512
```

Output is silent unless `--tone` is passed explicitly. The tone is a quiet
440 Hz diagnostic, not music playback. The stream requests 48 kHz stereo and a
graph quantum through its own node properties; it does not force global
PipeWire settings. Check the negotiated values in the report. Run one probe at
a time for a baseline, then repeat under a stated workload.

The same render core serves live callbacks and offline tests. The callback
uses preallocated data and collects bounded timing samples without logging,
disk I/O, UI calls or provider calls. Reported callback times cover application
processing, not speaker latency. PipeWire timing snapshots describe the graph;
a physical loopback test is still needed for end-to-end latency. Neither these
short runs nor the CI tests establish the later thermal-soak acceptance target.

For a build without Qt, configure another build directory with
`-DCONFLUX_BUILD_UI=OFF`. The audio test checks deterministic output across
different callback partitions, silence, channel equality and signal bounds.
Models, recordings, builds and local benchmark artifacts are ignored by Git.
Do not add model weights or third-party experiment checkouts to source history.

The separate [persistent stem worker](../tools/stems/README.md) loads one native
HTDemucs pipeline and delivers fixed-grid, overlapped output hops through a
bounded experimental supervisor. Seeks and cancellation invalidate a generation
immediately. An active Vulkan graph finishes before replacement work starts;
hard shutdown and request timeout can terminate the child. This tool stays out
of the audio callback and application build.

The [worker measurements](benchmarks/worker-2026-10-16.md) record continuous and
paced chunk delivery, forward/backward seeks, cancellation, queue bounds and
memory while native Wayland rendering and PipeWire output run concurrently.
The benchmark uses `--smoke-stop-file` and `--stop-file` to finish both probes
after all worker scenarios. PipeWire still renders the diagnostic stream;
application stem routing and the M1 deck work remain pending.

The [latency profiling rerun](benchmarks/latency-2026-10-16.md) records GPU clock
and wait behavior, the retained CPU wait changes, and mixed results against the
4.095-second hop p99 target under a temporary performance power profile.

The [follow-up stall trace](benchmarks/stall-trace-2026-10-16.md) records a
10.813-second hop, correlated GPU clock/power-limit behavior, benchmark scratch
cleanup and clean balanced-profile validation. M0 remains open for the
remaining workload and quality checks.

The [60-minute thermal soak](benchmarks/thermal-2026-10-16.md) verifies a full
hour of animated UI and independent audio coverage. Continuous hop p99 was
9.769 seconds against the 4.095-second target, with a maximum of 11.795 seconds
and 35 misses. Eleven cancellation/seek checks passed and the silent audio
probe recorded zero observed faults. The report preserves the earlier
incomplete UI attempts and the recurring low GPU clock/PL1 evidence. M0 remains
open; M1 has not started.

The [balanced-policy comparison](benchmarks/policy-2026-10-16.md) completes a
second hour with the same producer artifacts. Continuous hop p99 was 6.128
seconds, maximum 14.888 seconds, with 202/1,258 misses. All eleven controls and
audio/UI coverage checks passed. A 120-request native replay of the worst
window had no target misses; its shorter duration and different load do not
explain the sustained stalls or close M0.

The [audio/UI load-isolation follow-up](benchmarks/load-isolation-2026-10-16.md)
records repeated worker-only/audio-only output failures, the existing thermal
guard's policy interaction, and a completed hour that observes that guard
without changing profiles. Continuous p99 was 5.941 seconds, maximum 7.476
seconds, with 228/1,296 misses. All eleven controls and audio/UI coverage passed.
The remaining isolated conditions are paused at the user's request; M1 has not
started.
