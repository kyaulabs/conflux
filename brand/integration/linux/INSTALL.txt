Packaging template, not an installer. When shipping the application, install conflux.desktop.in as share/applications/conflux.desktop and copy hicolor/ into share/icons/hicolor/. Keep Icon=conflux extensionless. Verify Exec=conflux against the packaged binary. For Flatpak choose an application ID you own, rename the desktop/icon files to that ID, and update Icon accordingly. No ownership of a reverse-DNS namespace is assumed here. Keep scalable symbolic icons theme-colored. Qt Widgets QSS is a starter; Qt Quick/QML must map tokens to its own palette/components. Respect the desktop theme, keyboard navigation, high contrast and reduced motion. This brand pack does not implement Wayland windowing or an audio engine.
